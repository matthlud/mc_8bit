\section{Microarchitecture}
This chapter describes the microarchitecture of the Simple 8-bit CPU and provides a visual datapath diagram.

\subsection{High-level description}
The CPU is a single-cycle, accumulator-based design. There is no pipelining: on each rising clock edge, the PC, ACC and HALT state are updated. Instruction fetch reads IMEM[PC] into IR; the opcode is decoded in combinational logic to drive the datapath and control signals. Memory writes to DMEM occur in the sequential stage when a store is executed.

\subsection{Datapath and control}
The datapath components are:
\begin{itemize}
  \item Program Counter (PC) -- 8-bit register (low 4 bits used for addressing internal memory).
  \item Instruction Memory (IMEM) -- 16 x 8-bit ROM/array.
  \item Instruction Register (IR) -- holds fetched instruction.
  \item Decoder / Control Logic -- combinational logic deriving control signals from IR[7:4].
  \item Accumulator (ACC) -- 8-bit register used by ALU operations.
  \item ALU -- supports ADD and SUB; combinational, 8-bit result feeds next ACC.
  \item Data Memory (DMEM) -- 16 x 8-bit array with write enable.
\end{itemize}

\subsection{Frequency and area estimation}
A Yosys-based generic synthesis was performed to provide a gate-count and ABC timing estimate. Results are summarized in the following subsection.

\subsection{Synthesis results (summary)}
\begin{itemize}
  \item Cell / gate count: \textbf{790} (from Yosys RTL synthesis)
  \item Estimated worst-case combinational depth: \textbf{~12--20 gate stages} (decoder + ALU path, conservative)
  \item Conservative frequency estimate (\texttt{f\_max}): \textbf{200--800 MHz} (technology-dependent — see assumptions below)
  \item Area estimate: \textbf{790 NAND2-equivalents} which maps to the following approximate silicon area ranges depending on process assumptions:
  \begin{itemize}
    \item 65 nm (assume 1.0\,\textmu m\textsuperscript{2} per NAND2): $\approx$ 790\,\textmu m\textsuperscript{2} $= 0.00079\,$mm\textsuperscript{2}
    \item 28 nm (assume 0.25\,\textmu m\textsuperscript{2} per NAND2): $\approx$ 197.5\,\textmu m\textsuperscript{2} $= 0.00020\,$mm\textsuperscript{2}
  \end{itemize}
\end{itemize}

\subsection{Assumptions and notes}
The frequency and area numbers above are back-of-envelope estimates only. They were produced using the following conservative assumptions:
\begin{itemize}
  \item Gate count reported by Yosys ("cells") is treated as NAND2-equivalents for area estimation.
  \item Combinational depth along the critical path (decoder + ALU) is assumed in the 12--20 gate stage range; actual depth depends on synthesis optimizations and mapping to library cells.
  \item Typical single-gate delays vary widely by technology and driving conditions; the 200--800\,MHz range is a conservative estimate covering small standard-cell processes and typical FPGA slices. Actual \texttt{f\_max} must be obtained by timing analysis with a target cell library or by measuring the implemented FPGA bitstream.
\end{itemize}

See the full Yosys synthesis report in \texttt{artifacts/} for the raw cell counts and netlist; for precise timing and area numbers run technology mapping (e.g., Yosys+ABC or place-and-route) with a chosen standard-cell library or FPGA vendor toolchain.

\subsection{Discussion}
The design is small; the critical path is expected through the decoder + ALU feeding the ACC register. For an FPGA or standard-cell implementation, timing closure and area will vary with the chosen technology; see the full synthesis report in the repository artifacts.
